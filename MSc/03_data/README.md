# Data

Raw data is **not** stored in Git. The ADF2 Client Data-Sharing Package lives locally:

- `01_indicators/` breadth and meaningful-use indicators, 11 partners
- `02_clean_partner_data/` 11 de-identified farmer-level datasets
- `03_impact_evaluation_tables/` impact-evaluation results for ACRE Africa, DigiCow, AFEX, CoAmana, Zowasel

Record here: where the files are kept, the data-use agreement terms (including whether publication and co-authorship are allowed), and a data dictionary for the variables you use.
