# MSc research: Vicky Jebet

MSc Agricultural Information and Communication Management, Department of Agricultural Economics, University of Nairobi (expected 2027).

Working area: secondary analysis of the AgriFin Digital Farmer 2 (ADF2) evaluation data (Mercy Corps AgriFin), aimed at a thesis that also yields at least one peer-reviewed journal article.

## Folders

| Folder | What goes here |
|---|---|
| `01_proposal/` | Proposal drafts, concept notes, supervisor feedback log |
| `02_literature/` | Literature matrix, search log, reading notes (no copyrighted PDFs) |
| `03_data/` | **Data is never committed.** Only the data dictionary, data-use agreement notes and a README on where the raw files live |
| `04_analysis/` | R scripts / notebooks, in run order (`01_clean.R`, `02_descriptives.R`, ...) and output tables/figures |
| `05_thesis/` | Thesis chapters, following the UoN Agricultural Economics structure |
| `06_publications/` | Journal article drafts, target-journal notes, cover letters, reviewer responses |
| `07_prompts/` | AI prompt toolkit for the research workflow |
| `admin/` | Timeline, milestones, ethics clearance, forms |

## Rules

- No raw or farmer-level data in this repository, even though the ADF2 package is k-anonymised. Keep it on your computer or a private drive.
- Every claim in a chapter traces to a source in the literature matrix or to a script in `04_analysis/`.
- AI helps think, critique and edit. It never supplies facts, numbers or references that have not been checked against the original source.
